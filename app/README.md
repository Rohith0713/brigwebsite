# Brig Radio - Frontend Application

This directory contains the core React application for Brig Radio.

## Features

- **Real-time Shared Listening**: Experience music with others in sync.
- **Social Discovery**: Find new music through community recommendations.
- **Modern UI**: Built with Radix UI and Tailwind CSS for a premium feel.
- **GSAP Animations**: Smooth, high-performance visual transitions.

## Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 7](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v3.4](https://tailwindcss.com/), [Shadcn UI](https://ui.shadcn.com/)
- **State/Logic**: [React Hook Form](https://react-hook-form.com/), [Zod](https://zod.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Available Scripts

In the `app` directory, you can run:

- `npm run dev`: Starts the development server.
- `npm run build`: Compiles the application for production.
- `npm run lint`: Runs ESLint for code quality checks.
- `npm run deploy`: Deploys the application to GitHub Pages.

## Directory Structure

- `src/`: Main source code
  - `components/`: UI components (including Shadcn primitives)
  - `sections/`: Higher-level page sections
  - `hooks/`: Custom React hooks
  - `types/`: TypeScript definitions
- `public/`: Static assets
- `dist/`: Output directory for builds
